# Trusted Web Activity packaging

This folder is the Bubblewrap input for a future Play package. It does not
contain a keystore, an AAB, or a real signing fingerprint. Do not upload a
build to Play Console from this config until Play Billing replaces in-app SaaS
checkout. STK for the platform subscription stays on the web and PWA.

`packageId` `com.sellfindconnect.app` is a proposed id. It is not a Play app
yet. `com.telpen.edu` is a different product and must not be reused.

`assetlinks.json` is a template. The fingerprint string is not a certificate.
Do not publish it at `https://sellfindconnect.com/.well-known/assetlinks.json`
until the steps below replace that string.

## Keystore, build, Digital Asset Links

1. Install Bubblewrap (`npm i -g @bubblewrap/cli`) and the Android SDK.
2. From this directory, create a keystore you keep outside git:

   ```
   keytool -genkeypair -alias sellfindconnect -keyalg RSA -keysize 2048 -validity 10000 -keystore android.keystore
   ```

3. Build and sign:

   ```
   bubblewrap update
   bubblewrap build
   ```

   Bubblewrap writes the signed AAB next to this manifest. The keystore path
   in `twa-manifest.json` is `./android.keystore`.
4. Print the upload-key SHA-256:

   ```
   keytool -list -v -keystore android.keystore -alias sellfindconnect
   ```

5. Replace `REPLACE_WITH_COLON_SEPARATED_SHA256_FROM_THE_UPLOAD_KEY` in
   `assetlinks.json` with that fingerprint. If Play App Signing is on, use the
   **app signing** certificate fingerprint from Play Console as well.
6. Publish the filled file at
   `https://sellfindconnect.com/.well-known/assetlinks.json` and confirm
   `https://digitalassetlinks.googleapis.com/v1/statements:list?source.web.site=https://sellfindconnect.com&relation=delegate_permission/common.handle_all_urls`.
7. Create the Play app yourself, upload the AAB, and paste
   `docs/PLAY_LISTING_PACK.md` into the store listing. Do not press Submit
   until counsel review, a reviewer account, and the Kenya tax approval are done.

The server Play Billing adapter is `GooglePlayBillingPaymentAdapter`, selected
with `PAYMENT_PROVIDER=play`. It verifies a client `purchaseToken` in
`customerReference` and fails closed without `GOOGLE_PLAY_PACKAGE_NAME` and
`GOOGLE_PLAY_ACCESS_TOKEN`. The Android purchase UI, the service-account token
refresh, and Play Console product ids are still outside this repository.

Placeholder icons are generated by `python3 scripts/generate-placeholder-icons.py`.
Swap the PNGs in `apps/web/public/icons/` before a production build. The
maskable file the manifest serves is `maskable-512.png`.
